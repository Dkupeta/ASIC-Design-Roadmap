# ASIC flow reading plan

1. Read the SKY130 process documentation and understand the educational/open-PDK scope.
2. Follow the OpenROAD Flow tutorial to understand platform, design, constraints, logs, reports and results directories.
3. Read Yosys documentation for RTL synthesis and technology mapping.
4. Read OpenLane 2 documentation to understand an alternative integrated RTL-to-GDS flow.
5. Use Verilator/cocotb for simulation and SymbiYosys for selected formal properties.
6. Record the exact tool and PDK versions used for every experiment.
